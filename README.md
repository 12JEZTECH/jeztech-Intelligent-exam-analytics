# JEZTECH Academic Intelligence

Multi-school academic management platform for Kenyan schools using CBC/CBE and 8-4-4.

## Stack
- React + TypeScript frontend
- FastAPI backend
- PostgreSQL / Supabase-ready database
- Docker Compose and Render Blueprint
- GitHub Actions CI

## Local run
1. Copy `.env.example` to `.env`, replace the secrets.
2. Run `docker compose up --build`.
3. API docs: http://localhost:8000/docs
4. Web app: http://localhost:5173

See backend and frontend directories for source code and README for security notes.
